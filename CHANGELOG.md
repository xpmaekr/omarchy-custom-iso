# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-11-08

### Добавлено

- Для русского языка в установленной системе автоматически включаются
  раскладки `us` + `ru`, а переключение работает по **Alt+Shift** (вместо
  стандартного для Omarchy Left Alt + Right Alt). Патч `build-root-image.sh`
  меняет `default/hypr/input.lua` внутри root image; upstream checkout
  по-прежнему не модифицируется.

## [1.0.0] — 2026-11-08

Первый публичный релиз.

### Добавлено

- Textual TUI: поиск по AUR и репозиториям Arch, выбор пакетов, журнал сборки,
  переключение языка (русский/английский), настройки checkout и пароля sudo.
- Поиск и проверка пакетов через AUR RPC и отдельный pacman-конфиг только с
  `core`/`extra`/`multilib`/`omarchy` (на CachyOS не подменяет пакеты
  репозиториями `cachyos-*`).
- Сборка AUR-пакетов и их зависимостей через `paru -G --aur` и
  `makepkg --nodeps --nocheck`: выбранные приложения не устанавливаются на
  хост, ставятся только build-зависимости.
- Патчи `omarchy-iso-make` и `builder/build-iso.sh` во временном build root из
  симлинков: upstream checkout остаётся неизменным.
- Предустановка собранных AUR-пакетов и обычных repo-пакетов в offline mirror
  и root image ISO.
- CLI: `--check`, `--search`, `--verify`, `--prepare`, `--list`, `--build`,
  `--version`.
- Неинтерактивная сборка целиком: `omarchy-custom-iso --build`.
- Журналы сборок в `~/.local/state/omarchy-custom-iso/logs/`.
- Юнит-тесты без сети и без pacman/paru, GitHub Actions CI и workflow релиза
  по тегу `v*`.

### Исправлено

- **Build root `builder/` — реальная копия, а не симлинки.** Docker монтирует
  этот каталог в контейнер, где абсолютные симлинки на хост-пути не
  существуют; из-за этого первая же строка `source /builder/node-release.sh`
  падала. Полная сборка ISO теперь проходит.
- Быстрое добавление пакетов больше не создаёт дубликаты строк в списке
  выбранного (refresh-воркеры выполняются эксклюзивно).
- Длинные строки журнала переносятся, а не обрезаются по правому краю.
- `pacman -V` в отчёте окружения показывает версию, а не ASCII-логотип.
- Понятная ошибка, если в checkout нет каталогов `archiso`/`configs`.
- Пароль sudo по умолчанию больше не `12345`: пустое поле означает обычный
  запрос sudo, конкретный пароль задаётся в настройках.
